Project 2

My project will be a website that is based on the video game "Brawl Stars". There are currently 111 total brawlers, with 7 different rarity tiers, 7 different classes, and many more statistics and abilities. This website will help players explore information about different brawlers, including their health, damage, gadgets, Star Powers, Hypercharges, and other abilities. The main purpose of this website is to allow players to save personalized brawler builds for certain game modes. Users will be able to select a brawler, choose their preferred gadgets and Star Powers, and save their build for future reference. Additionally, users will have the ability to add notes to their builds, such as tips for using the brawler effectively or strategies for specific game modes. This website will also allow users to view, edit, and delete their saved builds. I will be using the Brawl Stars API to retrieve up-to-date information and Firebase Firestore to save user builds. The overall goal of this website is to be a easy-to-use resource for new and experienced players.
