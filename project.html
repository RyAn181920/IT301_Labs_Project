Project Description

My upcoming project will be a static website advertising local businesses and attractions in Harrisonburg, VA.

The website will feature a modern design with easy navigation and mobile responsiveness to ensure an adequate user experience on all devices.

There will be a homepage, including a navigation menu that will allow users to easily access different sections of the site.

The goal is to create an easy-to-use website that provides valuable information to users interested in local businesses and attractions.
